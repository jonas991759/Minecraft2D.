Minecraft 2D – Android

Dein Spiel ist für Android vorbereitet.

Touch:
- ◀ / ▶ = laufen
- ↑ = springen
- ABBAU / SETZEN = wechseln
- Tippen in der Welt = Aktion
- INV = Inventar
- PAUSE = Pause

APK:
GitHub → Actions → Build Minecraft 2D APK → Run workflow
Danach das Artifact Minecraft2D-APK öffnen.
